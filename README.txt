# SLNS Earthmovers & Contractors — Website

This is a complete responsive starter website based on the supplied reference image.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive design
- `script.js` — mobile navigation and active-section behavior
- `assets/` — visual assets cropped from the supplied reference image

## Before publishing
Replace these placeholders in `index.html`:
- `+91 XXXXXXXXXX`
- `info@slnsearthmovers.in` if the email is different
- WhatsApp number in `script.js`/`index.html` link (`91XXXXXXXXXX`)

You can also replace the cropped reference images with your real company logo, machinery photos, project photos and team photos.

## Local preview
Open `index.html` in a browser. No build system is required.

## GitHub Pages
Upload all files and folders while keeping the same structure. Then enable GitHub Pages from the repository's Settings → Pages.
